VAULT ZERO — OBSIDIAN EDITION

Файлы:
- index.html — главная страница
- wiki.html — интерактивная вики
- corebreaker.webp — исходный арт Corebreaker без изменений
- vaultzero.css — единый визуальный стиль обеих страниц

Как открыть: распакуйте все файлы в одну папку и откройте index.html в браузере.
Для публикации загрузите всю папку на статический хостинг с сохранением путей.

Сохранены: интерактивная дверь хранилища, ссылки на Roblox, работающие поиск и фильтры вики, страницы записей, точки анатомии Corebreaker, частица/параллакс из исходного кода.

Важно: изображения shatterheart.webp и goblin-scout.webp отсутствовали в загрузке; вместо битых изображений показаны стилизованные заглушки. Вики содержит исходные записи/данные без выдуманных характеристик.
Шрифты Forum и Golos Text подгружаются с Google Fonts, когда есть сеть; предусмотрены системные замены.
Необходимости в сборщике, Node.js или фреймворке нет.
