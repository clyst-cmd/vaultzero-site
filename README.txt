VAULT ZERO — AETERNA ARCHIVE SITE

ФАЙЛЫ
index.html — Главная + кликабельные 8 Vault с раскрывающимися предметами.
vaults.html — Отдельный каталог Vault с открывающимися коллекциями, фильтрами редкости.
wiki.html — Все 48 предметов, поиск, фильтры, индивидуальные страницы с концепт-лором.
style.css — Общая адаптивная стилистика.
data.js — Каталог Vault / оружия и тексты художественного лора.
site.js — Интерактивность, фильтры, динамические страницы.
assets/vaults/ — 8 изображений сундуков, оптимизированные WebP.
assets/items/ — 48 полноразмерных изображений оружия WebP (из предыдущего пользовательского архива).
assets/thumbs/ — облегчённые превью для сетки.

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория (не ZIP и не саму внешнюю папку).
В Settings > Pages включите Deploy from a branch > main > / (root).
Сохраняйте относительную структуру папок без изменений.

ВАЖНО
- Состав Vault, названия предметов, редкости и статусы изображений перенесены из двух архивов пользователя.
- Картинки самих сундуков из последнего архива пользователя.
- Новые тексты описаний каждого предмета — авторский художественный КОНЦЕПТ-ЛОР, а не утверждённый канон VAULT ZERO.
- Статус 'Арт готов' обозначает готовность предоставленного арта, а не подтверждение доступности в Roblox.
- Не добавлены вымышленные HP, DPS, вероятность выпадения или игровая стоимость.
- Ничего не меняется и не публикуется в Roblox; это статический сайт для GitHub Pages.
